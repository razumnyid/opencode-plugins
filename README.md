# opencode-plugins

OpenCode v2 plugins.

## Plugins

- `image-clipboard` — save pasted/dragged images to disk and insert a text marker.
- `tts` — read the last assistant message aloud with `edge-tts` (`Ctrl+Alt+R` toggle).

## Install

Clone into OpenCode's plugin directory:

```bash
git clone git@github.com:razumnyid/opencode-plugins.git ~/.config/opencode/plugins
```

OpenCode auto-discovers plugins in `~/.config/opencode/plugins/`.
